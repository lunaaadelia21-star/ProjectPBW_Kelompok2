KELOMPOK 2 WEB

Cara menjalankan:
1. Buka folder ini di VS Code.
2. Pastikan file index.html dan semua file profil berada dalam folder yang sama.
3. Klik kanan index.html lalu pilih Open with Live Server, atau buka index.html langsung di browser.
4. Untuk foto profil, letakkan file foto sesuai nama yang dipanggil oleh masing-masing HTML:
   - Rafi: pasfoto.jpg
   - Luna: fotokelompok.jpeg
   - Revalia: Revalia.jpeg
   - Shafira: sarippa.jpg
   - Rasya: foto gueh.jpeg
